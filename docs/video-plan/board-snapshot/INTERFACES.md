### I-001 · A2 · 2026-10-30 14:00
- `datasets/video_io.py` (torch-free): `VideoReader(path_or_bytes, backend='auto'|'torchcodec'|'pyav'|'opencv')`; `.metadata()` -> `VideoMetadata(fps, frame_count, duration, width, height, codec, backend, frame_count_exact, variable_fps, rotation)`; `.get_frames(indices, clamp_to_end=False)` -> uint8 `[T,H,W,3]` RGB, exact presentation-order indices, any order/repeats; `.iter_frames(width=None, gray=False)` streams every frame in order (one in memory); `.get_motion_vectors(indices, block_size=8, method='auto'|'codec'|'farneback', per_frame=True)` -> `MotionField(field [T,2,ceil(H/b),ceil(W/b)] float32 (dx,dy), is_intra [T], source, ...)`; `.motion_curve('auto'|'codec'|'framediff')` -> `[frame_count]`; `.time_to_index(sec)`, `.fingerprint()`. Errors: `VideoDecodeError(ValueError)`, `MotionVectorsUnavailable`.
- MV convention: pixels/frame, sign = later minus earlier (+dx right, +dy down, same as Farneback prev->next); I-frames zero + is_intra. Exact for single-ref codecs; `reencode_for_motion_vectors(src, dst)` gives CoViAR-style MPEG-4 P-only. `flip_motion_field(f)` mirrors + negates dx.
- For S1a `iter_frames()` `(index, rgb, sampled)`: wrap as `for i, f in enumerate(VideoReader(p).iter_frames()): yield i, f, i in wanted` — or `get_frames(sorted_indices)` for sparse sampling.
- `datasets/video_sampling.py`: `SamplingSpec(strategy, num_frames, clip_stride, clip_duration_sec, temporal_jitter, speed_perturb)`; `sample_clip_indices(frame_count, spec, train, rng, num_clips, fps, start_frame, end_frame, motion)` -> int64 `[num_clips, num_frames]`.
- `datasets/video_datasets.py`: `open_video_dataset(df_or_path, transform, num_frames, clip_transform, train=, options=VideoDataOptions, num_clips=)` auto-detects `videos` = paths (`VideoDataset`) or bytes (`ParquetVideoDataset`); `ParquetVideoDataset.from_parquet` does the same. Items `(clip [T,C,H,W] or [N,T,C,H,W], label[, extras])`. Frame-cache hook (B1): override `_decode_frames(i, reader, indices)`; key `clip_key(i)`. `video_loader_kwargs(ds, bs, shuffle, num_workers)`.
- Manifest columns: `videos` (path), `labels`, optional `group`, `start_sec`, `end_sec`, passthrough extras.
- CLI (cli.py `add_video_data_arguments`, also infer.py): `--video_backend --temporal_sampling --clip_stride --clip_duration_sec --motion_source --test_clips --num_workers` (+ train: `--video_storage paths|bytes --video_augment --video_flip --video_speed_perturb`). All saved in cli_arguments.json.
- `src/video/multi_clip.py`: `MultiClipModel` averages softmax probs over N clips (returns log mean p); `clip_disagreement(per_clip, mode)`; inference column `clip_disagreement` when `--test_clips > 1`.

### I-002 · A3 · 2026-10-30 03:21
- Generator (torch-free, branch video/A3-phase2-benchmarks): `python -m benchmarks.synthetic_motion --task direction|speed|periodic|untrimmed|scene_bias --out DIR [--seed --size --num_frames --n_train --n_test --n_val --bias --n_videos --min_length --max_length --n_classes --background_motion static|distractor|mixed --fps --codec auto|mp4v]`; Python: `make_<task>_dataset(out, ..., seed)` -> `BenchmarkDataset(root, manifest, metadata, masks, splits{train,val,test}, codec, classes, extra)`. Deterministic per clip from (seed, task, split, index).
- Layout: `videos/<id>.mp4`, `manifest.csv` + `train/val/test.csv` (same columns), `dataset.json`, `masks.npz`; untrimmed adds `gt_segments.csv` (`video-id,t-start,t-end,label`) and `gt_activitynet.json` (`database[vid].annotations[].segment=[t0,t1]`, `subset` training/validation, `duration`, `fps`).
- Manifest columns: `videos` (relative path), `labels` (class name / float speed / untrimmed `;`-joined classes), `label_idx` (index into sorted classes = LabelEncoder order), `group`, `split`, `video_id`, `background_family`; scene_bias `family_matches_class`; untrimmed `label_<class>` multi-hot, `num_frames`, `fps`, `duration_sec`, `background_motion`. No `start_sec/end_sec` columns (A2's loader would treat them as clip trims).
- `dataset.json`: task, seed, params, codec, fps, size, classes, `hflip_safe`, `vflip_safe`, videos{id: file, split, group, num_frames, mask_shape, centers[T] (null where no blob), velocity|motion, background_family; untrimmed: segments[{label, label_idx, start_frame, end_frame (exclusive), t_start, t_end, radius, motion}], background_intervals [[s,e)], background_motion, distractor, multi_hot}.
- Background mask: `benchmarks.synthetic_motion.load_blob_masks(root, video_id)` -> bool [T,H,W], True = blob/action pixel; untrimmed: blob present iff frame inside a segment (tested on decoded pixels).
- Flip guard: `benchmarks.guards.check_flip_augmentation(dataset_dir|dataset.json|manifest|meta_dict, hflip=, vflip=, strict=True)` raises `UnsafeAugmentationError` on direction-labelled data (direction, scene_bias, untrimmed); no-op for non-benchmark data. A2's `--video_flip` should call it.
- Model: `--pooling single_frame` (utils.build_video_model -> `src/video/single_frame.py`, middle frame T//2; native 3D rejects it). Runner: `scripts/run_motion_benchmark.py --task direction|scene_bias|periodic --models single_frame:resnet18 mean:resnet18 attention:resnet18 r3d_18 flow_logreg`.
