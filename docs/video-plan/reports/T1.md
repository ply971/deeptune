## Decisions
- **`isinstance` alone does not fix LoRA.** PEFT builds each adapter with `type(base_layer)(in, r, kernel, stride, padding, bias=False)`, which `Conv3DSimple`'s constructor rejects. `plain_conv_subclasses` therefore changes those modules' class to `nn.Conv3d` in place. Those subclasses differ only in the constructor; a test confirms outputs and state-dict keys are unchanged. A subclass with its own `forward` is left out.
- **Old checkpoints** load through `adjustedPeftVideo3D.load_state_dict`: plain weights move to `base_layer`, and new adapters get `lora_B = 0`, so the delta is exactly zero. Anything else gets an error naming the flags to check.
- **`--seed` in `deeptune.py` also selects the fixed split**, so repeated seeds share one test set.
- **Resume refuses different train/val data** (size, plus a hash of file size and first and last MiB), because continuing could leak trained samples into test. `--resume_allow_data_change` overrides it. Changed settings only warn.
- **Checkpointing turns off persistent workers.** Their RNG cannot be saved, and they draw no new base seed, so a resume would diverge. This costs worker respawns each epoch on Windows.
- **Validation is plain cross-entropy** even with smoothing or mixup, so selection scores stay comparable. It runs under autocast; the error-model fit and `TestTrainer` run without it.
- **Accumulated gradients are summed per sample and divided by the window's sample count**, which matches the big-batch gradient even when the last batch is smaller.
- **`--freeze_bn` default stays `off`**, as there is no evidence yet for changing it. It freezes both statistics and BN parameters, and only in the backbone (a new head has no pretrained statistics). The Trainer takes `backbone_pretrained` (default False), which `train.py` sets from the model version; only `dummy*` versions use `weights=None`. `on` without pretrained weights is obeyed with a warning.
- **Selection record for R2:** `validation_used_for_model_selection`, `selection_metric` and `best_epoch` are in `error_model_fit.json`, and `training_run.json` has a `selection` block. The error model is still fitted on validation; a separate split is R2's job.

## Open problems
1. **LoRA on r3d_18 costs about 98k parameters per rank** (was about 1.9k), because `lora_A` keeps the conv's 3x3x3 kernel. Any result recorded for LoRA on r3d_18 reflects the old 4-of-20 coverage. The default rank of 16 is about 1.6M.
   - The other PEFT models still tie rank to head width, so a tight budget can still give them a 1-wide head. `--lora_rank` tells the user it is ignored there.
   - `scripts/run_motion_benchmark.py` passes no rank, so its native PEFT models keep rank = embed_size.
2. **GPU paths never ran:** the bf16/fp16 tests skip without CUDA, and the scaler logic is tested with a double. Exact resume is shown on CPU only; `cudnn.deterministic` is not set (`training_run.json` now records that), so GPU runs may differ.
3. **Resume with real DataLoader workers was not run**, because spawning is too heavy for this laptop. `seed_worker` and the persistent-workers override are only checked as units.
4. **`--freeze_bn auto`'s cutoff of 16 is unmeasured** and compares clips per batch. A frame-pooled 2D backbone sees B x T frames, but they are highly correlated, so I counted clips. Whether freezing helps needs the UCF101 r3d_18 check.
5. **`--test_crops` is not the Kinetics 3-crop protocol.** Views are 7/8 windows of the already-resized frame, resized back, so do not compare its numbers with the papers'.
6. **Other limits:**
   - `src/vision/*_peft.py` other than Swin still use `type(m) in [...]`. Coverage is partial on EfficientNet (65 of 81, grouped convs are skipped) and ConvNeXt (36 of 58, linears only); every adapter they have does train.
   - The data fingerprint samples each file's ends, and for path manifests it hashes the manifest, not the videos.
   - A `store_true` flag set in a config file cannot be turned off on the command line.
   - Peak memory is recorded per run next to its options; there is no table comparing options.
