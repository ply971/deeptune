## What was built
| `--video_arch` | Implementation | Backbones |
|---|---|---|
| `frame_pool` | G5: pools embeddings, then the head classifies. Old checkpoints are detected by the missing `pool_format` key and keep logit pooling. | any 2D, `siglip` |
| `single_frame` | From Phase 2, kept | any 2D, `siglip` |
| `late_fusion` | First and last frames, concatenated, FC merge | any 2D, `siglip` |
| `early_fusion` | First convolution inflated to 3T channels | ResNet family |
| `slow_fusion` | Selects a native 3D model, default `r2plus1d_18` | native 3D |
| `tsm` | Shift inside the residual branch, no extra parameters, 2D names unchanged | ResNet family |
| `cnn_rnn` | LSTM or GRU over frame features | any 2D, `siglip` |
| `temporal_transformer` | CLS token, learned positions starting from sinusoidal | any 2D, `siglip` |
| `two_stream` | Middle RGB frame + L stacked motion fields, `--fusion avg\|fc`, `--motion_source farneback\|mv`, disk cache, `extract_embed='separate'` | ResNet family |

- **SigLIP** is a frame backbone for train, eval and embed (`--model_version siglip`, also with `--use-peft`), from the command line only.
- **Records.** The architecture is stored as a spec in `pooling`, for example `tsm:tsm_fold_div=8`. `build_video_model` parses it, so trainers, evaluators, embedding, `infer.py` and the desktop Test page needed no special cases. Runs recorded before this phase parse as before.
- **`flow_probe` bug:** confirmed fixed in the uncommitted diff. Periodic and speed use the flow summary; direction and scene_bias keep the mean flow. New test `test_flow_probe_separates_periodic` (at least 0.9 at 60 training clips).
- **Interfaces:** board entry I-010.

## Bugs found while reviewing the earlier work (fixed, with tests)
1. **Embedding pooling crashed on DenseNet with `added_layers=1`.** Its `extract_embed=True` returned logits, contrary to its docstring. Fixed in `src/vision/densenet.py` and `densenet_peft.py`. **This also changes the images modality:** DenseNet embeddings with one added layer are now the features, not class logits. Weights and predictions are unchanged. Please check this is acceptable.
2. **SigLIP resize had no antialiasing,** unlike the PIL resize in its image processor. A shrunk frame differed from what the model expects. Now checked against PIL.
3. **The benchmark runner sent `mean:siglip` through the ImageNet transform.** It now uses SigLIP's preprocessing.
4. **`--motion_length` above the clip's frames, and `--tsm_fold_div 1`,** are now refused when the model is built.

### How far to trust these numbers
- **One seed.** Thresholds (0.85, 0.62, 0.25) are not pre-registered; I inherited them with the earlier work and did not change them.
- **The tiny backbone favours some models.** `resnet_tiny` keeps a 2x2 grid, chosen because it lets frame-comparing models see motion with fewer clips. Its own docstring records `cnn_rnn` at 0.495 from 240 clips with a global pool. Real ResNets pool globally, so `cnn_rnn`, `late_fusion` and `temporal_transformer` may need much more data there. **This is the result most likely to change on the GPU.**
- **`late_fusion` does not pass the default direction task.** At the default speeds it measured 0.505-0.555 with 800 clips, because two frames on the wrap-around world cannot decide the direction. It passes on a slower variant. PLAN.md's done-when asks for the direction task, so please decide whether this counts.
- **`temporal_transformer` needed 1500 clips and a changed start.** The earlier run moved it to normalised tokens and sinusoidal starting positions after near-chance results (0.575 at 240 and 800 clips).
- **Shuffled frames:** the assertion is on the mean of three orders. Single orders can stay high (0.825).
